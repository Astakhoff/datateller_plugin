# Плагин DataTeller для Claude и Codex

Публичный репозиторий содержит один плагин DataTeller: каталог, метрики, отчёты,
права и мониторинг через единый MCP-вход `https://app.datateller.ai/mcp`.

## Подключение внутри приложения

Установите пакет из публичного источника `Astakhoff/datateller_plugin` штатными
средствами своего клиента. В карточке установленного плагина используйте **Connect**,
лично пройдите OAuth и запустите `dt-setup` (в Codex — предложенный Setup).
Он читает действующую системную методику через `datateller_plugin_setup_guide`:
общую секцию и одну секцию целевого клиента. Установка не подтверждает готовность оценок.

Состав и исходные требования: [README плагина](plugins/datateller/README.md).

| Путь | Содержимое |
|---|---|
| `.claude-plugin/marketplace.json` | Каталог плагина |
| `plugins/datateller/` | Пакет DataTeller |

В репозитории нет исполняемого кода, секретов и клиентских данных.
Пакет публикуется из основного репозитория DataTeller; прямые изменения этой копии
заменяются при следующем выпуске.
