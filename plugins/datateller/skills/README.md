# Скиллы DataTeller

Три деловых скилла остаются короткими указателями на серверные методики:

| Скилл | Методика |
|---|---|
| `dt-create-report` | `catalog_report_guide` |
| `dt-manage-access` | `catalog_access_guide` |
| `dt-create-metric` | `catalog_metric_guide` |

`dt-setup` — отдельный сценарий первоначальной настройки Codex desktop. Он объявлен
как onboardingSkill в манифесте Codex и ведёт пользователя через подключение и
личную проверку двух хуков внутри приложения. Это не новая деловая методика.
Другим клиентам он не обещает элементы интерфейса Codex.

Имена начинаются с `dt-`, описания — со слова DataTeller. Деловые правила и методики
остаются на сервере; setup не копирует их и не выдаёт доверие клиенту самостоятельно.
