# DataTeller: настройка

До OAuth предложи только штатный **Connect** в карточке установленного плагина.
Вход выполняет пользователь. Без подключения методика недоступна; не выдумывай её.
После OAuth прочитай `datateller_plugin_setup_guide(section="common")`.
По её правилам выбери целевой клиент пользователя и прочитай только одну секцию
того же инструмента: `section="claude"` либо `section="codex"`.
Следуй полученной действующей методике. Не подменяй её локальными инструкциями,
не угадывай неизвестный клиент и не объявляй готовность без проверки.
